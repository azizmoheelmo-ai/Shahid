# شاهد على الأداء الوظيفي

تطبيق ويب (صفحة واحدة) لمتابعة الأداء الوظيفي للمعلم، يشمل:

- تسجيل الدخول وإدارة الحساب (Supabase Auth)
- خطة الأداء الوظيفي، الأهداف، والتقييم الذاتي
- تسجيل "الشواهد" (الأدلة) وتصديرها كـ PDF / Word ومشاركتها عبر واتساب
- إدارة الصف (طلاب، شعب، سجلات سلوكية) والمتابعة الأكاديمية وخطابات الإحالة
- لوحة تحكم للمشرف/الأدمن (إحصائيات، صلاحيات، سجل تدقيق)
- نسخ احتياطي وتصدير شامل للبيانات (Excel / CSV / PDF / ZIP)

## التقنيات

- HTML / CSS / JavaScript (بدون إطار عمل، صفحة واحدة)
- [Supabase](https://supabase.com) كخدمة خلفية (مصادقة، قاعدة بيانات، تخزين ملفات)

## التشغيل محلياً

الملف `index.html` مستقل بالكامل — يكفي فتحه في المتصفح، أو تقديمه عبر أي خادم استضافة ثابت (static hosting).
